# 日本株テンバガー判定・運用ルール v0.4

- 状態: 全額テンバガー運用の前向きPAPERベースライン。実資金へは未昇格
- 発効日: 2026年9月1日
- 基準版: [v0.2](tenbagger-rule-v0.2.md)
- 今回変更する層: 資金配分とポジション上限だけ
- 目的: この運用へ割り当てた資金の100%をテンバガー戦略の対象とし、固定的な安全資産枠を持たない

本書は利用者が、この運用へ与える資金とは別に安全資産を確保していると明示したことを前提にする。運用資産は全額を失っても生活、納税、近い将来の支出へ影響しない資金に限る。この前提は損失を防ぐものではなく、v0.4では運用資産の大部分または全部を失う可能性がある。

本書に明記した変更以外の対象銘柄、データ品質、入口判定、採点、10倍逆算、価格・時間ルール、利益確定、流動性、注文方法、撤退条件、再購入禁止はv0.2をそのまま適用する。競合する資金配分規則だけ本書を優先する。

## 1. 資金の分類

| 区分 | 運用資産に対する比率 | 扱い |
|---|---:|---|
| テンバガー戦略資金 | 100% | 合格した新規候補または条件を満たす追加購入へ配分できる |
| 固定的な安全資産 | 0% | この運用内には設けない |
| 戦略待機資金 | 0〜100% | 未投資の戦略資金。安全資産とは数えず、次の適格な購入機会まで待機する |

戦略待機資金に最低比率も最大比率も設けない。合格候補がなければ100%待機になり得る一方、すべての上限を満たす候補が揃えば取得原価ベースで100%まで投資できる。投資比率を満たすために70点未満の銘柄を買う、月次評価を飛ばす、四半期開示前に追加する、100株単位を理由に上限を超えることは禁止する。

税、手数料、未約定注文に必要な現金は戦略運営上の資金であり、安全資産枠ではない。注文額と費用の合計が利用可能現金を超える注文は作らない。

## 2. v0.4の購入上限

| 項目 | v0.2 | v0.4 |
|---|---:|---:|
| 初回購入 | 運用資産の1% | 運用資産の5% |
| 1回の追加購入 | 運用資産の0.5% | 運用資産の2.5% |
| 追加回数 | 最大2回 | 最大2回 |
| 1銘柄の累計取得原価 | 運用資産の3% | 運用資産の10% |
| 候補群の累計取得原価 | 運用資産の20% | 運用資産の100% |
| 同一業種の累計取得原価 | 運用資産の6% | 運用資産の20% |
| 同時保有 | 最大12銘柄 | 最大12銘柄 |
| 信用・借入 | 禁止 | 禁止 |

初回5%、追加2.5%を2回という3段階は、1銘柄上限10%を `50% / 25% / 25%` に分ける。10銘柄が累計10%まで合格すれば100%を配分できる。最大12銘柄は常に12銘柄を持つ目標ではなく、100株単位や候補数に応じて1銘柄10%未満へ分散する余地である。同一業種20%により、100%投資時は最低5業種へ分散しなければならない。

すべての比率は目標ではなく絶対上限である。新規候補は通常の月末評価でのみ購入し、追加購入はv0.2の四半期条件をすべて満たした場合だけ行う。株価下落だけを理由とする追加や、余った資金を埋めるための追加を行わない。

## 3. 情勢指数と実際の上限

`MRS-v0.1`の倍率は各購入枠へ適用する。

| MRS | 初回購入上限 | 1回の追加上限 | 新規・追加 |
|---|---:|---:|---|
| `NORMAL` | 5% | 2.5% | 許可 |
| `CAUTION` | 2.5% | 1.25% | 半減して許可 |
| `STRESS` | 0% | 0% | 禁止 |
| `UNAVAILABLE` | 0% | 0% | 禁止 |

実際の注文上限は、上表、1銘柄累計10%、候補群100%、同一業種20%、最大12銘柄、利用可能現金、100株単位、流動性上限の最小値とする。1つでも計算不能なら`WAIT`とする。

## 4. 待機資金の記録

日次レポートと月次レビューでは、次を区別して記録する。

- 運用資産に対する取得原価ベースの投資済み比率
- 戦略待機資金比率
- 未約定注文に拘束中の比率
- 新規候補用と、四半期条件を待つ追加購入用の予定比率
- 投資できない理由と次の判定日

戦略待機資金を「安全資産」「元本保全資金」「投資対象外」と表現しない。待機期間の損益は現金として計算し、機会損失を隠さない。合格候補がない期間に現金が残ることはルール違反ではないが、固定的に80%を残すこともルールではない。

## 5. 売却と再配分

v0.2の部分利確または全売却で得た資金は、利用可能になった時点から戦略待機資金へ戻す。次の月末の新規候補、または次の四半期開示後に追加条件を満たした保有銘柄へ、通常の上限内で再配分する。売却しただけで再投資済みと扱わず、実際の約定イベントを台帳へ記録する。

1銘柄の時価が運用資産の20%を超えた場合に15%まで縮小する`S-D6`は変更しない。取得原価10%まで投資できることは、上昇後の時価集中を放置する許可ではない。

## 6. PAPER検証とLIVE昇格

v0.4は資金配分を大きく変えるため、v0.2の成績をそのまま流用しない。PAPERではv0.4を運用判断に使い、同じ候補と約定条件でv0.2およびv0.3を反実仮想として保存する。

最低限、次を比較する。

1. 費用控除後の期末資産と最大ドローダウン
2. 投資済み比率、戦略待機資金比率、現金加重待機日数
3. 銘柄別・業種別の集中と最大損失寄与
4. 追加購入前後の損益と、追加しなかった反実仮想
5. 100株単位、流動性、候補不足で配分できなかった比率

v0.4を`LIVE`へ昇格するには[運用ガバナンス](../operations/operation-governance-v0.1.md)の全ゲートに加え、v0.4凍結後に開始した未観測のpoint-in-time全母集団holdoutでv0.2より大きくなる集中損失を利用者が確認して、`v04_holdout_promotion`を明示承認する。PAPERの経過日数と連続run数には最低条件を設けない。一方、holdout planに事前固定した観測数と損失floorは満たす必要がある。

通常LIVE前に少額の実約定を観察する場合は、[制限付き実運用](../operations/limited-live-v0.1.md)に従い
`LIMITED_LIVE`を使う。このモードは専用資金の絶対上限、1 run 1新規注文、追加購入禁止、
累積損失停止を機械的に強制するが、forward holdoutや通常LIVE gateを代替しない。

[2025年の12か月過去データ実験](../research/tenbagger-v0.4-allocation-replay-2025.md)は、同じ代理候補へv0.2とv0.4の資金配分を適用し、投資率・損益・最大ドローダウンの増幅だけを診断する。財務・開示を使う正式な候補判定や本人のLIVE承認を代替しない。

2025年1月1日〜2026年8月31日はv0.4発効前なので、正式な全入力を再構築できても回顧的stress testとして扱い、`predeclared` holdoutとは呼ばない。入力契約、成果物、forward holdoutの手順は[point-in-time履歴再生](../operations/historical-replay-v0.1.md)を正本とする。

本ルールは運用資産を安全資産として守る設計ではなく、高リスク戦略内で強制購入と過度な単一銘柄・業種集中を避ける設計である。将来の利益、10倍到達、元本回収を保証しない。
