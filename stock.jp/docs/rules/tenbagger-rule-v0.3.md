# 日本株テンバガー判定・運用ルール v0.3

- 状態: 凍結済みチャレンジャー。全母集団の未見期間でv0.2と比較するまで実資金へ昇格しない
- 凍結日: 2026年8月31日
- 基準版: [v0.2](tenbagger-rule-v0.2.md)
- 今回変更する層: 購入後の価格・時間・利益確定ルールだけ
- 目的: ルール数を減らし、既知の成功例への過剰適合を抑えながら、5倍時に原資相当を回収して次の候補へ回せるようにする

> 運用注記（2026年9月1日）: 現行PAPERは資金配分だけを変更した[v0.4](tenbagger-rule-v0.4.md)である。本書の凍結内容は変更せず、v0.3はシャドー比較として継続する。

v0.3はv0.2を置き換えて成績改善を宣言する版ではない。v0.2を現行ベースライン、v0.3を簡素化した比較候補として同時に凍結する。全上場銘柄、非成功銘柄、上場廃止を含む未見期間でv0.3がv0.2を上回るまで、優位性があるとは扱わない。

本書に明記した変更以外はv0.2をそのまま適用する。競合した場合だけ本書を優先する。

## 1. なぜ複雑化ではなく簡素化するか

[v0.2価格ルールの参考損益](../research/tenbagger-v0.2-price-only-pnl-2016-2026.md)では、事後に判明した現存テンバガー83銘柄に価格で実行可能な条件を適用した。

- v0.2価格ルールは83銘柄中51銘柄で売却なしを上回り、32銘柄で下回った
- 合計は762.99単位で、売却なし769.89単位を6.90単位下回った
- 10倍後の `S-D4` 全売却29銘柄は247.77単位となり、売却なし141.63単位を上回った
- 10倍前の `S-C1`、`S-C3`、`S-C4`、`S-C5` は、後に10倍となる7銘柄を損失で全売却した

ただし、83銘柄は後から成功が分かった正例だけである。早期売却条件が非成功銘柄の損失をどれだけ防いだかは測れていない。正例で成績が良くなる数値へ閾値を動かすことも、早期売却を直ちに廃止することも、このデータだけでは正当化できない。

同じデータで多数の仕様を試し、最も良いものを選ぶほど偶然を選ぶ危険が高まる。Whiteは同一データをモデル選択へ繰り返し使うdata snoopingを扱い、Baileyらは試行した構成数が増えるバックテスト過剰適合を定式化した。Harveyらも、多数の候補を試す金融研究では通常より厳しい検証が必要になることを示している。

したがってv0.3では、過去83銘柄の最大利益を探さない。条件間の重複を減らし、投資目的に直接対応する境界だけを残す。

## 2. v0.3で変えないもの

次は検証データが不足しており、価格売却と同時に変更すると原因を分離できないためv0.2から変更しない。

- 成功ラベル、対象市場、別トラック
- データ品質とハードゲート
- 100点スコアと70点の一次候補閾値
- SAM、SOM、競合比較、10倍の逆算
- 初回1%、候補群20%、同一業種6%、最大12銘柄、1銘柄取得原価3%の上限
- 追加購入、流動性、注文執行
- `S-A1`〜`S-A6` の即時全売却
- `S-B1`〜`S-B5` の決算による縮小・全売却
- 63営業日の再購入禁止

100点スコアを「正しい」と認めたわけではない。全母集団で、1株売上成長だけ、モメンタムだけ、その組み合わせなどの単純ルールに未見期間で勝てなければ、次版で配点を減らす。v0.3で入口と出口を同時に変更しないこと自体を過学習防止策とする。

## 3. 価格・時間ルールの簡素化

### 3.1 変更一覧

| v0.2 | v0.3 | 扱い |
|---|---|---|
| `S-C1` | `V3-P1` | 50%下落を全売却から特別レビューへ変更 |
| `S-C2`〜`S-C5` | — | 63・126・252・504営業日の自動売却判定を停止 |
| `S-C6` | `V3-P2` | 3暦年の目的未達売却を維持 |
| `S-D1` | `V3-P3` | 5倍で20%売却を維持し、回収資金として管理 |
| `S-D2` | `V3-P4` | 10倍で追加30%売却を維持 |
| `S-D3`、`S-D5` | — | スコアと価格を組み合わせた到達後条件を停止 |
| `S-D4` | `V3-P5` | 10倍後の50%トレーリング全売却を維持 |
| `S-D6` | `V3-P6` | ポートフォリオ集中上限を維持 |

価格・時間に関する判定は、v0.2の12条件からv0.3の6条件へ減り、そのうち売買条件は5条件となる。`V3-P1` は警報だけで売買条件ではない。新しい数値閾値は追加せず、v0.2に存在した値だけを使う。

### 3.2 正式ルール

| ID | 判定時点 | 条件 | 行動 |
|---|---|---|---|
| `V3-P1` | 各月末 | 月末終値が `PA` の50%以下 | 5営業日以内に特別レビュー。価格だけでは売らない |
| `V3-P2` | 初回購入から3暦年 | `MA20 < 10 × PA` | 目的未達として残量を全売却 |
| `V3-P3` | 初めて月末終値が `5 × PA` 以上 | 翌営業日に `0.20 × Q0` を売却 |
| `V3-P4` | 初めて月末終値が `10 × PA` 以上 | 翌営業日に追加で `0.30 × Q0` を売却 |
| `V3-P5` | `V3-P4` 到達後の各月末 | `DD20 <= -50%` | 残量を全売却 |
| `V3-P6` | 各月末 | 1銘柄の時価が運用資産の20%超 | 15%になるまで売却 |

`PA`、`Q0`、`MA20`、`H20`、`DD20` の定義はv0.2を引き継ぐ。判定日の終値で約定したことにせず、利用可能な最初の翌営業日終値をモデル約定にする。

`V3-P1` の特別レビューでは、最新情報でv0.2のハードゲート、100点スコア、主要KPI、資金余力、希薄化、SAM/SOMを再計算する。成立した `S-A` または `S-B` 条件だけで売買し、「50%下がったから仮説も悪いはず」という推測を売却理由にしない。

最初の月末到達が10倍以上なら `V3-P3` と `V3-P4` を同時に適用し、合計 `0.50 × Q0` を売却する。すでに `S-B` または `V3-P6` で残量が予定売却数未満なら現在残量を上限とする。

### 3.3 早期の原資回収と回収資金の再配分

`V3-P3` は、約定価格が正確に `5 × PA` なら税・費用控除前の累計投下額に相当する現金を回収する。実際の約定価格、税、費用によって一致しないため「元本回収を保証する」とは表現しない。

回収の目的は損失リスクを下げることに加え、別の合格銘柄へ投資できる余力を早く作ることである。ただし、売却しただけで再配分効果が生じたとは数えない。次をすべて守る。

1. 回収資金は実際に再投資可能となった日以後の現金として記録する
2. 新規購入は通常の月末評価でv0.2の入口条件をすべて満たした銘柄だけに行う
3. 初回1%、候補群20%、同一業種6%、最大12銘柄、流動性上限を緩めない
4. 合格銘柄がなければ現金のまま保有し、70点未満を買う、既存銘柄へ理由なく追加する、次の候補を先読みすることは禁止する
5. 回収から再投資までの日数、現金待機額、再投資先、再投資後リターンを記録する

検証する仮説は「早く原資相当を回収すれば常に有利」ではなく、「回収後、通常ルールに合格した別銘柄へ実際に再投資できた場合、ポートフォリオ全体の資金効率が改善する」である。合格候補がなければ、再配分による収益上の効果はゼロであり、現金待機と元銘柄を20%減らした機会損失が残る。

バックテストでは、銘柄ごとに独立して売却代金を足し上げるだけでは資金再配分を評価できない。時系列ポートフォリオを作り、各時点に実在した合格候補と利用可能現金を突き合わせる。候補がなかった期間の現金待機を含め、再投資できた場合だけ再配分の効果として計上する。

### 3.4 優先順位

同じ日に複数条件が成立した場合は次の順に適用し、同じ株数を二重に売らない。

1. `S-A1`〜`S-A6` の即時全売却
2. `S-B1`〜`S-B5` の決算による全売却・縮小
3. `V3-P2` の3暦年全売却
4. `V3-P5` の10倍後全売却
5. `V3-P3` の5倍到達時20%売却と `V3-P4` の10倍到達時30%売却
6. 利益確定後の残量で判定する `V3-P6` の集中縮小

`V3-P1` はレビュー開始の印であり、この優先順位の売買条件には含めない。

## 4. この簡素化の意図とリスク

### 意図

- 2〜3年で10倍という目的に対し、「10倍到達」「3年の期限」という自然な境界を残す
- 63、126、252、504営業日、1.2倍、1.5倍、8倍などの中間境界を売買条件から外す
- 価格下落と企業仮説の崩壊を分ける
- 5倍で投下額相当を回収し、合格候補が実在するときだけ再配分する
- 到達後は1本のトレーリング条件と集中上限だけにする

### リスク

- 非成功銘柄を価格だけで早く切れず、1銘柄の損失が大きくなる可能性がある
- 5倍で売却した20%分は、その銘柄がさらに上昇した場合の利益を失う
- 次の合格候補がなければ回収資金は現金として待機し、再配分による収益向上は生じない
- `DD20 <= -50%` 自体も未見期間では検証されておらず、最適値ではない
- 財務・開示条件が遅れて判明する場合、価格警報から実際の撤退まで時間がかかる

これらは、初回1%、候補群20%、同一業種6%、無借金運用というポジション上限で抑える。上限が守れない運用へv0.3を流用しない。

## 5. 過学習を防ぐ検証契約

### 5.1 複雑度予算

1. v0.3で変更するのは購入後の価格・時間ルールだけとする
2. 比較するチャレンジャーは本書の1案だけとし、閾値グリッドを回さない
3. 83成功銘柄でv0.3の優位性を判定しない
4. 試したが採用しなかった版、閾値、除外条件も試行回数へ含める
5. 業種、時価総額、相場局面ごとの結果を見てから個別閾値を作らない
6. 未見期間の結果を一度確認した後にv0.3を修正しない

### 5.2 比較データ

- 各評価月の全対象銘柄を使い、上場廃止、合併、TOBを含める
- v0.2とv0.3へ同じ購入候補、同じ約定モデル、同じ費用を使う
- v0.3は「回収資金を合格候補へ再配分する本線」と「同じ売却を行い回収資金を現金のまま置く対照」の2台帳を作り、再配分だけの寄与を分離する
- 発見期間と未見期間の間に3年のパージ期間を置く
- 売却後の価格も追跡し、損失回避と機会損失を両方記録する
- 5倍到達件数、回収額、再投資できた割合、現金加重の待機日数、再投資先の損益、対照台帳との期末資産差を報告する
- 83成功銘柄は実装確認にだけ使い、モデル選択の標本へ再利用しない

### 5.3 昇格条件

未見期間で、費用控除後の時系列ポートフォリオについて次をすべて満たした場合だけv0.3を現行版へ昇格する。

1. v0.2より期末資産が低くない
2. v0.2より最大ドローダウンが大きくない
3. 売買回数がv0.2より多くない
4. データ欠損、未約定、上場廃止を有利に除外していない

収益とドローダウンのどちらか一方だけが改善した場合は優劣不明とし、v0.2を維持する。未見期間に合わせて条件を変更した版はv0.4として新しいデータを待ち、同じ未見期間で再判定しない。

## 6. 実装用の最短フロー

~~~text
v0.2の入口条件を満たして購入
  ↓
S-A / S-Bが成立 ── はい → v0.2どおり撤退・縮小
  │ いいえ
  ↓
3暦年でMA20が10倍未満 ── はい → 全売却
  │ いいえ
  ↓
月末5倍へ初到達 ── はい → Q0の20%売却、回収資金へ
  │
  ↓
月末10倍へ初到達 ── はい → Q0の30%を追加売却
  │
  ↓
10倍後にDD20が-50%以下 ── はい → 残量全売却
  │ いいえ
  ↓
1銘柄が資産の20%超 ── はい → 15%まで縮小
  │ いいえ
  ↓
保有継続
~~~

月末50%下落はこのフローとは別に特別レビューを開始するが、それ自体では売却しない。回収資金は、別の合格候補がある場合だけ通常の購入上限内で使い、なければ現金のまま待機する。
