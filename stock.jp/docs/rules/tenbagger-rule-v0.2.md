# 日本株テンバガー判定・運用ルール v0.2

- 状態: 凍結済み基準版。v0.4 PAPERの銘柄選定・出口基準およびシャドー比較
- 発効日: 2026年8月31日
- 対象期間: 2年または3年
- 初期ユニバース: 東証上場の内国普通株
- 目的: 同じ手順で候補選定、購入、保有、縮小、売却を再現する

v0.2は[v0.1](tenbagger-rule-v0.1.md)と[2016–2026年の予備検証](../research/tenbagger-validation-2016-2026.md)を基礎にする。予備検証では、現存銘柄の `10x-3Y` 82銘柄のうち最終日にも10倍以上だったのは24銘柄、35銘柄は到達後に80%以上下落した。これを受け、持続性ラベル、到達後リスク、価格・時間・仮説崩れによる売却、利益確定、執行手順を追加する。

一方、現存銘柄だけの正例探索から70点閾値や売却閾値を最適化すると過剰適合になる。100点の配点、一次候補70点、時価総額を固定ゲートにしない方針はv0.1から変更しない。v0.2の新しい運用閾値は、上場廃止を含む全母集団検証が終わるまで暫定とする。

| v0.1からの変更 | v0.2での扱い |
|---|---|
| 10倍後の結果 | 12か月後の維持、最終倍率、到達後ドローダウンを追加 |
| 価格データ品質 | 再上場、コード変更、分割・併合の接続をハードゲート化 |
| 購入後の判断 | 確認頻度、再採点、時間・価格条件を固定 |
| 利益確定 | 5倍で20%、10倍で追加30%を基準株数から売却 |
| 仮説崩れ | 監査、開示、希薄化、資金余力、SAM/SOM、スコアで縮小・撤退 |
| 注文と再購入 | 翌営業日執行、流動性上限、63営業日の再購入禁止を追加 |

本ルールは仮説検証とペーパートレードの仕様であり、将来の利益や条件価格での売却を保証しない。実資金へ使う場合は、資産全体、税務、生活資金、損失許容度を別途確認する。

## 1. 成功ラベルの定義

### 評価日と投資開始価格

各月末を評価日 `T0` とする。判定材料に使えるのは `T0` の取引終了までに公表済みの情報だけとし、評価価格 `PE` は `T0` の分割調整後終値とする。投資開始価格 `P0` は翌営業日 `T1` の分割調整後終値とする。翌日終値を使うのは、開示直後の寄り付きで約定できたと仮定することを避け、再現可能な価格に統一するためである。

`PE` はスコアと10倍の事前逆算にだけ使い、`P0` は成功ラベルと実現リターンにだけ使う。`P0` を候補選定へ使ってはならない。実運用では約定後に実際の取得単価で逆算を更新する。

### テンバガー

- `10x-3Y`: `P0` に対し、3年以内のいずれかの月末終値が10倍以上
- `10x-2Y`: `P0` に対し、2年以内のいずれかの月末終値が10倍以上
- 補助ラベル `touch-10x`: 期間中のいずれかの日次終値が10倍以上
- 補助ラベル `durable-10x`: 20営業日平均終値が10倍以上
- 補助ラベル `retained-8x-12M`: `durable-10x` 初回到達から12か月後の20営業日平均終値が8倍以上
- 補助ラベル `terminal-10x`: 十分な追跡期間がある銘柄で、データ最終日の20営業日平均終値が10倍以上

株式分割・併合は調整する。配当は株価10倍の定義に含めず、配当込みリターンは補助指標とする。月末終値を主ラベルにするのは、一日だけの急騰を成功と数えにくくするためである。

データ最終日を `D` とすると、完全に判定できる評価日は `T1 + 判定期間 <= D` を満たすものに限る。`retained-8x-12M` は初回到達から12か月を経過した銘柄だけを分母にする。`terminal-10x` は評価日から最低3年を経過した銘柄だけを比較し、直近コホートを持続失敗にしない。具体的な締切日を文書へ固定せず、データ更新時に計算する。

上場廃止、合併、株式交換、現金対価の買収は失敗例として単純削除しない。最終取引価格、受取現金、承継株式を記録し、株価ラベルと投資リターンを分けて扱う。

## 2. 検証対象

初期検証は、ETF、ETN、REIT、インフラファンド、優先株、TOKYO PRO Market、外国株を除く、評価日時点で東証に上場していた内国普通株を対象とする。2022年4月以前の市場区分も当時点の区分を使う。

以下はリターン発生の構造が違うため、本体ルールと混ぜず別トラックにする。

- 創薬・臨床試験など二値性の高いバイオ
- 資源探査・暗号資産保有を主因とする銘柄
- 金融業
- 上場後12か月未満のIPO
- 債務超過からの再建、法的整理を伴うターンアラウンド

地方市場はデータ整備後に追加し、東証で決めた閾値をそのまま流用せず別途検証する。

## 3. 入口のハードゲート

ハードゲートは、事業の良し悪しではなく、データの信頼性と3年間生存できる最低条件に限定する。全条件を満たした銘柄だけを採点する。

1. `T0` 時点の株価、発行済株式数、潜在株式、現預金、有利子負債を使って、完全希薄化後時価総額と企業価値（EV）を算定できる
2. 上場後12か月以上かつ、比較可能な四半期開示が8四半期以上ある
3. 債務超過または継続企業の前提に関する重要な疑義がない
4. 直近の監査意見が無限定適正であり、法定開示の重大な遅延がない
5. フリーキャッシュフローがマイナスの場合、評価日時点の利用可能現金で12か月以上の資金余力がある
6. 行使価額修正型新株予約権など、最大希薄化率を合理的に算定できない資金調達が残存していない
7. 上場、再上場、コード変更、株式分割・併合を追跡でき、評価価格から投資開始価格まで同一の経済的持分として接続できる

資金余力は、直近6か月の月平均現金減少額を基準に計算する。利用可能現金から使途制限付き預金を除き、未実行融資枠は金融機関の確約があるものだけを加える。一時的な運転資本変動や直近の確定済み資金調達がある場合は調整内容を記録する。

### 時価総額

時価総額に固定の下限・上限は設けない。絶対額だけでは、その企業が属する市場の大きさや競合に対する相対的な小ささを判定できないためである。

過去検証では `T0` 時点の時価総額を「30億円未満」「30億円以上100億円未満」「100億円以上300億円未満」「300億円以上1,000億円未満」「1,000億円以上」に層別し、規模帯別にルールの有効性を測定する。規模帯は除外条件ではなく説明変数とする。

### 売買可能性

流動性は企業の質と分離し、現在候補へ適用する直前に判定する。

~~~text
撤退所要日数 = 予定投資額 ÷ (直近20日平均売買代金 × 許容参加率)
~~~

予定投資額と許容参加率を引数として保存する。バックテストでは複数の投資額と売買コストを試し、流動性の低い成功例を黙って除外しない。

## 4. 100点スコア

すべて `T0` 時点の公表値から採点する。総額の成長ではなく、原則として希薄化後1株当たりの成長を使う。

データ取得処理の欠損は `NA` として採点を止める。会社が重要KPIを開示していない場合は0点とする。採点値、根拠資料、公表日、計算式を保存し、第三者が同じ点数を再現できるようにする。

1株当たり指標の分母には各測定期間の平均完全希薄化後株式数を使う。増減率は比較元が正の値の場合だけ計算し、売上高または粗利益が0以下なら該当成長項目を0点とする。`TTM` は評価日時点で公表済みの直近4四半期合計とする。

### 4.1 売上・粗利益の成長: 20点

| 指標 | 採点 |
|---|---|
| 3年売上高/希薄化後株式数CAGRを `x` とする | `x < 0%=0`、`0% <= x < 10%=1`、`10% <= x < 20%=3`、`20% <= x < 30%=6`、`30% <= x=8` |
| TTM売上高/希薄化後株式数の前年比を `x` とする | `x < 0%=0`、`0% <= x < 10%=1`、`10% <= x < 20%=3`、`20% <= x < 30%=6`、`30% <= x=8` |
| TTM1株粗利益成長率 − TTM1株売上成長率を `x` とする | `x < 0pt=0`、`0pt <= x < 5pt=2`、`5pt <= x=4` |

### 4.2 成長の加速: 10点

| 指標 | 採点 |
|---|---|
| TTM1株売上成長率 − 1年前のTTM1株売上成長率を `x` とする | `x <= 0pt=0`、`0pt < x < 5pt=2`、`5pt <= x < 10pt=4`、`10pt <= x=5` |
| TTM1株粗利益成長率 − 1年前のTTM1株粗利益成長率を `x` とする | `x <= 0pt=0`、`0pt < x < 5pt=2`、`5pt <= x < 10pt=4`、`10pt <= x=5` |

### 4.3 営業レバレッジ: 15点

| 指標 | 採点 |
|---|---|
| TTM営業利益率の前年比変化を `x` とする | `x < 0pt=0`、`0pt <= x < 2pt=2`、`2pt <= x < 5pt=4`、`5pt <= x=6` |
| TTM粗利益成長率 − TTM販管費成長率を `x` とする | `x < 0pt=0`、`0pt <= x < 5pt=1`、`5pt <= x < 10pt=3`、`10pt <= x=5` |
| 正規化FCFマージンを `x` とする | `x < 0%`かつ悪化=0、`x < 0%`かつ改善=1、`0% <= x < 5%=2`、`5% <= x < 10%=3`、`10% <= x=4` |

正規化FCFは「営業CF − 通常の事業維持・成長に必要な設備投資」とし、FCFマージンは売上高で割る。大型M&A、一時的な資産売却、特殊な補助金を除くが、通常の成長投資に必要な設備投資は除外しない。

### 4.4 市場余地と競合ポジション: 15点

| 指標 | 採点 |
|---|---|
| `SAM-3Y` の根拠 | 第三者資料で再計算可能=3、会社推計だが前提を検証可能=1、検証不能=0 |
| 3年後必要シェア | 現首位シェアの50%以下=4、50%超100%以下=3、首位超えだが定量的経路あり=1、経路なし=0 |
| 必要販売・生産能力 | 現状実績または契約済み能力で裏付け=4、資金確保済み計画で裏付け=2、説明のみ=0 |
| 市場成長とシェア獲得 | 両方を実績で確認=4、片方のみ=2、どちらも未確認=0 |

### 4.5 継続性・競争優位: 10点

| 指標 | 採点 |
|---|---|
| 継続率、解約率、反復購入率 | 2年以上改善または高位安定=4、1年分のみ確認=2、未開示・悪化=0 |
| 顧客単位の採算 | 粗利・回収期間等が改善=3、一部のみ確認=1、未確認=0 |
| 差別化の証拠 | シェア、価格、継続率等で確認=3、定性的説明のみ=1、なし=0 |

### 4.6 財務・資本配分: 10点

| 指標 | 採点 |
|---|---|
| 資金余力を `x` か月とする | FCF黒字または`36 <= x`=4、`24 <= x < 36`=3、`12 <= x < 24`=1 |
| 3年希薄化後株式数CAGRを `x` とする | `x <= 0%=3`、`0% < x <= 3%=2`、`3% < x < 7%=1`、`7% <= x=0` |
| 3年累計営業CF/3年累計営業利益を `x` とする | `80% <= x=3`、`0% < x < 80%=1`、`x <= 0%=0` |

3年累計営業利益が0以下の企業では、「増加粗利益 ÷ 現金消費額」の3年推移で代替し、改善=3、横ばい=1、悪化=0とする。分母が0以下または指標を計算できない場合は0点とする。

### 4.7 経営・開示品質: 5点

| 指標 | 採点 |
|---|---|
| KPIの定義と継続性 | 3年以上一貫=2、変更理由と接続表あり=1、未開示・接続不能=0 |
| 初期会社予想の精度 | 直近3期の主要指標の絶対乖離中央値10%以内=2、10%超25%以内=1、25%超=0 |
| 関連当事者取引・資本配分 | 重要取引の条件と合理性を検証可能=1、検証不能=0 |

営業赤字企業では会社予想の主要指標を売上高または会社が継続開示するKPIとする。

### 4.8 10倍の逆算可能性: 15点

| 指標 | 採点 |
|---|---|
| 3年後希薄化後株式数 | 既存潜在株と必要資金調達を反映=4、一部のみ反映=2、未反映=0 |
| 必要売上・利益のKPI分解 | 顧客数、単価、能力、利益率まで接続=4、一部接続=2、倍率だけ=0 |
| 出口倍率 | 同業中央値以下=4、同業中央値超かつ75%点以下=2、同業75%点超=0 |
| 競合規模との整合 | 競合以下または上回る定量的根拠あり=3、一部根拠=1、根拠なし=0 |

### 一次候補

- ハードゲートをすべて通過
- 合計70点以上
- 「市場余地と競合ポジション」が8点以上
- 「10倍の逆算可能性」が10点以上
- 未解決の重大なレッドフラッグがない

70点は過去検証前の仮説である。60点、70点、80点の成績を同時に報告し、発見用期間で選んだ閾値を未見期間では変更しない。

## 5. 10倍の逆算

### 株価10倍と希薄化

株価10倍に必要な将来時価総額は、現在時価総額の単純な10倍とは限らない。

- `PE`: `T0` 時点の評価価格
- `N0`: `T0` 時点の完全希薄化後株式数
- `N3`: 3年後の予想完全希薄化後株式数
- `ME = PE × N0`

~~~text
評価時点で株価10倍に必要と見積もる3年後時価総額 M10
  = 10 × PE × N3
  = 10 × ME × (N3 ÷ N0)
~~~

`N0` には自己株式を除き、株価が10倍になった場合に行使可能となる既存のストックオプション、新株予約権、転換証券を含める。`N3` には既存潜在株に加え、事業計画と資金不足から合理的に必要となる追加調達を基本・悪化シナリオで反映する。

潜在株式の行使代金による現金増加はEV計算で別に記録する。希薄化後株式数から黙って相殺しない。

### 必要業績

利益が見込める企業は次で逆算する。

~~~text
必要正規化純利益 = M10 ÷ 出口PER
必要売上高 = 必要正規化純利益 ÷ 想定純利益率
3年必要売上CAGR = (必要売上高 ÷ 現在TTM売上高)^(1/3) - 1
2年必要売上CAGR = (必要売上高 ÷ 現在TTM売上高)^(1/2) - 1
~~~

純利益率は同業上位25%を上回らない値を原則とし、上回る場合は価格、原価、顧客構成から説明する。特殊利益や税効果で必要利益を満たしてはならない。

赤字企業は企業価値を使う。非支配持分が重要な場合はEVへ加える。

~~~text
EV10 = M10 + 3年後有利子負債 + 3年後非支配持分 − 3年後現預金
必要売上高 = EV10 ÷ 出口EV/売上高
必要粗利益 = EV10 ÷ 出口EV/粗利益
~~~

売上総利益率が同業と大きく異なる場合はEV/売上高を使わず、EV/粗利益を優先する。

出口倍率は `T0` 時点の直接競合中央値を基本とする。PERは40倍、EV/売上高は8倍を安全弁として上限に置くが、業種別検証で閾値の妥当性を確認する。倍率上昇だけで10倍を説明することは禁止する。

### 市場規模との比較

会社が示す大きなTAMをそのまま使わず、次の3段階に分ける。

- `TAM`: 理論上の総市場
- `SAM-3Y`: 地域、顧客属性、規制、製品範囲を考慮し、3年以内に提供可能な市場
- `SOM-3Y`: 販売網、生産能力、人員、資金を考慮し、3年以内に現実的に獲得可能な売上

~~~text
3年後必要シェア = 3年後必要売上高 ÷ SAM-3Y
需要面の売上上限 = SAM-3Y × 到達可能シェア
SOM-3Y = min(需要面の売上上限, 販売・生産能力から見た売上上限)
到達可能粗利益プール = SOM-3Y × 持続可能な粗利益率
~~~

価値評価には市場売上高だけでなく、獲得可能な粗利益または営業利益プールも使う。必要売上高が `SOM-3Y` を上回る場合、10倍仮説は不成立とする。市場規模は原則として `T0` 以前に公表された第三者資料を使い、資料名、公表日、対象地域、対象顧客、推計方法を保存する。

必要シェアが現在の首位企業を上回る場合、販売能力、製品優位性、解約率、価格、供給能力などから逆転の経路を説明できなければ「10倍の逆算可能性」は6点以下とする。

### 競合企業との比較

直接競合3〜5社は、将来リターンを確認する前に、業種、収益モデル、顧客、地域から選定ルールを固定する。市場シェア比較には非上場企業も含め、評価倍率には上場している直接競合を優先する。上場直接競合がない場合だけ、収益構造と粗利益率が近い類似企業を使い、代替理由を記録する。各社について `T0` 時点の次の項目を比較する。

- 完全希薄化後時価総額とEV
- 売上高、粗利益、営業利益
- 売上成長率、粗利益率、営業利益率
- EV/売上高、EV/粗利益、PER
- 対象地域、市場シェア、事業構成

競合の時価総額は有用な上限確認になるが、それだけでは判定しない。現預金、負債、利益率、成長率、事業構成が異なるため、EVと事業KPIを揃えて比較する。

`M10` が最大の直接競合を超える場合、3年後に競合を上回る売上・利益、より広い市場、または明確に高い収益性を示せなければ逆算点を制限する。海外企業と比較する場合は、為替基準日、会計基準、上場市場の評価倍率差も記録する。

## 6. 運用ルール

### 6.1 運用の目的と変数

運用目的は「3年以内に10倍となる可能性へ参加しつつ、企業仮説が崩れた銘柄へ資金を固定しないこと」とする。すべての売買は、税引前・手数料控除前のモデル運用と、実際の約定を分けて記録する。

- `Q0`: 初回購入と承認済み追加購入の累計取得株数。分割・併合後の株数へ調整する
- `PA`: 手数料を除く加重平均実取得価格。成功ラベル用の `P0` と混同しない
- `d`: 初回購入日から数えた東証営業日数
- `Pd`: `d` 日時点の終値
- `Rd = Pd ÷ PA − 1`: 経過日リターン
- `MA20`: 20営業日平均終値
- `H20`: 初回購入後の `MA20` の最高値
- `DD20 = MA20 ÷ H20 − 1`: 平均価格ベースの高値からの下落率
- `S`: 最新公表情報だけで再計算した100点スコア

分割・併合後も `Q0` と `PA` を経済的に同じ持分へ調整する。配当は売却判定の株価倍率へ加えず、別に総リターンを記録する。

購入前に、10倍逆算へ使った顧客数、単価、販売・生産能力などから最大3つの「主要KPI」と四半期ごとの基本シナリオ値を固定する。実績が基本シナリオを15%以上下回るか、同じ定義での開示がなくなった場合を「主要KPI未達」とする。季節性があるKPIは前年同期と比較する。

### 6.2 確認頻度

| 頻度 | 確認内容 | 売買判断 |
|---|---|---|
| 随時 | 決算訂正、監査、資金調達、TOB、上場・売買停止、重大事故 | 即時売却条件だけを判定 |
| 毎週末 | 売買代金、ポジション比率、開示見落とし | 原則売買しない |
| 各月末 | 経過日ルール、`Rd`、`DD20`、利益確定 | 翌営業日に執行 |
| 四半期開示後5営業日以内 | 100点スコア、希薄化、資金余力、必要シェア、会社予想 | 継続・縮小・全売却 |
| 本決算後10営業日以内 | SAM、SOM、競合、出口倍率、3年逆算 | 投資仮説を更新 |

株価を日中監視して裁量売買しない。重大開示を除き、判定日は月末または決算後レビュー日に固定する。

### 6.3 購入と追加

1. ハードゲートをすべて通過し、合計70点以上、市場余地8点以上、逆算可能性10点以上でなければ購入しない
2. `T1` の寄り付き前に `1.15 × PE` を上限とする指値を置き、未約定なら追いかけず次の月末に全項目を再評価する。バックテストでは日中高安値と売買高を使い、指値で約定可能だった場合だけモデル購入する
3. 初回購入額は運用資産の1%を上限とする。候補群全体は運用資産の20%、同一業種の取得原価は6%を上限とし、信用取引・借入を使わない
4. 同時保有は最大12銘柄とする。同点なら逆算可能性、市場余地、流動性の順に優先する
5. 追加購入は四半期開示後だけとし、`S >= 75`、必要売上CAGRが悪化していない、累計希薄化見通しが増えていない場合に限る
6. 追加は1回0.5%、最大2回、1銘柄の累計取得原価3%までとする。株価下落だけを理由に平均取得単価を下げない
7. 平常時の許容参加率5%で全量を5営業日以内に売却できない金額は購入しない
8. 月末終値が初めて `5 × PA` へ到達した後は追加購入しない

上限比率は取得原価で判定する。株価上昇だけを理由に機械的な均等配分へ戻さず、利益確定とポートフォリオ上限を次節で扱う。

### 6.4 売却判断の優先順位

売却条件が同時に成立した場合は、`即時全売却`、`決算による全売却`、`価格・時間による全売却`、`部分売却`の順に適用する。同じ株数を二重に売らない。

#### A. 即時全売却

次のいずれかを公表情報で確認したら、価格水準にかかわらず次に売買可能な営業日から全量を売却する。

- `S-A1` 限定付適正、意見不表明、不適正の監査意見、継続企業の前提に関する重要な疑義、債務超過
- `S-A2` 法定開示の重大な遅延、重要な決算訂正、売上・利益・現預金等の信頼性を損なう虚偽または調査開始
- `S-A3` 最大希薄化を算定できない行使価額修正型新株予約権などの発行
- `S-A4` 取締役会が支持する現金対価の買収で、対抗提案または承継株式による上値を定量化できない
- `S-A5` 更新後の `S < 60`
- `S-A6` 更新後の必要売上高が `SOM-3Y` を超え、3年以内に解消する契約済み能力・資金・顧客経路がない

売買停止中は条件成立日と注文不能理由を記録し、再開時に新しい情報を反映して執行する。値幅制限や買い手不在により条件価格で売れるとは仮定しない。

#### B. 決算による縮小・全売却

| ID | 条件 | 1回目 | 2四半期連続 |
|---|---|---:|---:|
| `S-B1` | `60 <= S < 70` | `Q0` の3分の1を売却、追加禁止 | 残量を全売却 |
| `S-B2` | 市場余地8点未満または逆算可能性10点未満 | `Q0` の3分の1を売却 | 残量を全売却 |
| `S-B3` | 1株当たりTTM粗利益が前年比マイナス | 特別レビュー、追加禁止 | 残量を全売却 |
| `S-B4` | T0の基本シナリオに含まれない完全希薄化後株式数増加が、T0の `N0` 比で累計10%超 | 逆算を更新し `Q0` の半分を売却 | 残量を全売却 |
| `S-B5` | FCF赤字かつ資金余力12か月未満 | 全売却 | — |

「一時要因」を理由に継続する場合は、金額、終了日、正常化後指標を開示資料から事前に記録する。次回レビューで正常化しなければ2回目として扱う。

#### C. 価格・時間による売却

経過日ルールは初回購入日から数える。表の日が休場日なら次の営業日終値で判定し、翌営業日に売却する。`S` の条件がある行は、判定日から5営業日以内に最新公表情報で再採点する。

| ID | 判定時点 | 条件 | 行動 |
|---|---|---|---|
| `S-C1` | すべての月末 | 月末終値が `PA` の50%以下 | 全売却 |
| `S-C2` | 63営業日 | `R63 <= -30%` | 特別再採点し、`S < 70` または主要KPI未達なら全売却 |
| `S-C3` | 126営業日 | `R126 <= -40%` | 全売却 |
| `S-C4` | 252営業日 | `R252 <= -20%` | `S < 70` または購入後最高終値が `1.2 × PA` 未満なら全売却 |
| `S-C5` | 504営業日 | `R504 < 0%` | `S < 75` または購入後最高終値が `1.5 × PA` 未満なら全売却 |
| `S-C6` | 3暦年 | `MA20 < 10 × PA` | 目的未達として全売却 |

市場全体の急落だけを理由に条件を停止しない。ただし、取引所障害、価格データ異常、分割調整未反映の場合は売却せずデータを訂正する。TOPIX相対リターンは記録するが、それだけでは売却しない。

2016–2026年の現存 `10x-3Y` 82銘柄では、10倍到達前の日次終値で取得価格から50%以上下落した銘柄は3、月末終値では2だった。126営業日時点で40%以上下落は1、252営業日時点で20%以上下落は2、504営業日時点で取得価格未満は9だった。この正例だけでも一律損切りは将来の成功例を落とすため、126日以外の時間条件はスコアまたは進捗条件と組み合わせた。これは上場廃止と非成功例を含まない参考値であり、閾値の有効性を示すものではない。

#### D. 利益確定と10倍到達後

運用上の10倍到達は、月末終値が `10 × PA` 以上となった最初の月末とする。部分売却は累計取得株数 `Q0` に対して計算する。すでに他条件で残量が少ない場合は、現在残量を上限とする。

| ID | 到達条件 | 行動 |
|---|---|---|
| `S-D1` | 初めて月末終値が `5 × PA` 以上 | 翌営業日に `0.20 × Q0` を売却し、税引前の累計投下額相当を回収する |
| `S-D2` | 初めて月末終値が `10 × PA` 以上 | 翌営業日に追加で `0.30 × Q0` を売却する |
| `S-D3` | 10倍到達後、`DD20 <= -30%` かつ `S < 70` | `0.25 × Q0` を売却する |
| `S-D4` | 10倍到達後、`DD20 <= -50%` | 残量を全売却する |
| `S-D5` | 10倍到達から12か月後 | 全項目を再評価し、`MA20 < 8 × PA` かつ `S < 75` なら残量を全売却する |
| `S-D6` | 月末の1銘柄時価が運用資産の20%超 | 15%になるまで売却する |

最初の月末到達が10倍以上なら `S-D1` と `S-D2` を同時に適用し、合計 `0.50 × Q0` を売却する。5倍時の20%売却は、約定価格が `5 × PA` なら税・費用控除前の累計投下額に相当する。税引後の元本回収を保証する表現は使わない。10倍到達後もスコア75点以上で仮説が強まっている銘柄は残り50%を保有できるが、50%トレーリング条件と集中上限を解除しない。

### 6.5 注文執行

- 平常の月末・決算売却は、翌営業日から指値を使い、1日の売却額を直近20日平均売買代金の5%以下にする
- 即時全売却は価格より撤退を優先するが、成行で想定価格どおり売れるとは仮定しない。参加率10%を上限に分割し、板、値幅制限、売買停止を記録する
- バックテストのモデル約定は、判定情報を利用できる最初の翌営業日終値とし、同日終値で売れたことにしない
- 常設の逆指値注文は前提にしない。急変時には発動価格と約定価格が乖離し、短時間の下落で発動後に反発する可能性があるため、月末判定と翌日執行を基本にする
- 手数料、スプレッド、スリッページ、税金を別列で記録し、売却ルールの比較は費用控除後でも行う

### 6.6 再購入

全売却後63営業日は同じ銘柄を再購入しない。再購入には、新しい評価日、`S >= 75`、以前の売却原因の解消、最新価格からの10倍逆算成立をすべて要求する。単に株価が戻ったことは原因解消にしない。TOB、上場廃止決定、監査意見を原因とする売却後は再購入しない。

### 6.7 記録する運用ログ

各判断について次を1行で保存する。

- 銘柄コード、評価日、判断日、情報公表日時、判断時に利用可能だった資料
- ラベル用`P0`、実運用の`PA`、`Q0`、実約定、`d`、`Rd`、`MA20`、`H20`、`DD20`、TOPIX相対リターン
- 100点の各小項目、合計、必要時価総額、必要売上CAGR、SAM、SOM、競合倍率
- 成立した購入・売却条件のID、予定株数、注文種別、未約定理由
- 手数料、税、スプレッド、スリッページ、売却後の機会損失

裁量で例外を認める場合は、売買前に理由、期限、解除条件を記録する。事後に「長期保有へ変更した」ことにして失敗を隠さない。

## 7. レッドフラッグ

ハードゲートに該当しない場合でも、次の事象を確認する。未解決で投資仮説へ重大な影響があるものは候補から外し、除外理由を保存する。

- 総売上は伸びるが、希薄化後1株当たり売上または粗利益が伸びない
- 売上より売掛金、契約資産または在庫が大幅に速く増える
- 営業利益は増えるが営業キャッシュフローが継続的に悪化する
- 開発費の資産計上などで利益が押し上げられている
- 重要KPIの定義変更や開示停止が頻発する
- 下方修正、決算訂正、監査法人変更が反復する
- 大株主、役員、関連会社との取引条件を検証できない
- 大口顧客の喪失で事業継続が危うくなる集中度がある
- M&Aを除いた既存事業の成長率が継続的に低下する
- 会社公表のTAMが対象顧客、地域、単価へ分解できない
- 本業のKPIより材料性の高いPRが多い
- 株価上昇または継続的な増資を前提にしないと資金繰りが成立しない

## 8. 過去検証の方法

### 全母集団と対照群

適合率、再現率、候補数は、各評価月の全対象銘柄を母集団として計算する。成功銘柄と、同じ市場・業種・時価総額帯・上場年数に属する非成功銘柄とのマッチングは、特徴差を説明する補助分析にだけ使う。上場廃止銘柄も必ず含める。

同一銘柄の連続した評価月は、月次運用の検証では各時点を残す。企業単位の集計では、重複する2年・3年窓を一つの成功エピソードとしてまとめ、成功数を水増ししない。

### 比較対象

複雑な100点ルールが本当に有効かを確認するため、次の単純ルールとも比較する。

- 全銘柄均等
- 時価総額帯だけ
- 1株売上成長率だけ
- 過去12か月の株価モメンタムだけ
- 1株売上成長率とモメンタムの組み合わせ

### 測定値

- 主指標: 70点以上における `10x-3Y` のリフト
- 基準発生率: 全対象のうちテンバガーになった割合
- 再現率: 全テンバガーのうちルールが事前に拾えた割合
- 適合率: 候補のうち実際に10倍になった割合
- リフト: 適合率 ÷ 基準発生率
- `precision@K` と `recall@K`: 毎月上位K銘柄へ絞った成績
- 候補数と業種偏り
- 時価総額帯、市場区分、業種、相場局面別の成績
- 2年後・3年後リターンの中央値
- 10倍到達までの期間
- 到達前最大ドローダウン
- 50%以上下落、増資、債務超過、上場廃止の発生率
- `touch-10x` と `durable-10x` の差
- `retained-8x-12M` と `terminal-10x` の達成率
- 売却ルール適用後の実現倍率、保有日数、勝率、期待値、最大ドローダウン
- 各売却条件が成功例を早期に落とした割合と、失敗例の損失を抑えた割合
- 利益確定なし、全量10倍売却、v0.2部分売却の費用控除後比較
- 売買代金、値幅制限、想定スリッページを反映した実行可能性

主指標の不確実性は企業と暦年を単位とするブロック・ブートストラップで区間推定する。ルール変更は主指標だけでなく、再現率と50%以上下落率を悪化させていないか確認する。

正解率はテンバガーのような希少事象では意味が薄いため主指標にしない。適合率、再現率、リフト、大幅下落率を同時に見る。

## 9. バイアス防止

1. 株価、財務、株式数、上場区分、業種区分は `T0` 時点データを使う
2. 修正後の最新財務を過去へ遡って使わず、当時公表された値を使う
3. 財務は会計期間末ではなく実際の開示日時以後にだけ利用可能とする
4. 市場規模資料と競合情報も `T0` 以前に公表されたものだけを使う
5. 競合は将来リターンを見る前に機械条件または記録済み手順で選ぶ
6. 上場廃止、合併、倒産銘柄を母集団から落とさない
7. 株式分割、併合、株式交換、銘柄コード変更を追跡する
8. データ取得の欠損と会社による未開示を区別する
9. 発見用期間と未見期間の間に、最長判定期間と同じ3年のパージ期間を置く
10. 未見期間で閾値、重み、除外条件を変更しない
11. 試したルール数と棄却した変更も記録し、多重検定を隠さない
12. 現在候補の抽出は未見期間でルールを一度評価した後に行う
13. 購入だけでなく、売却条件、部分売却率、再購入禁止期間、モデル約定日も未見期間の前に固定する
14. 売却後の株価も追跡し、損失回避と機会損失の両方を報告する
15. 経過日ルールは営業日と暦年を混同せず、企業ごとの売買停止日を日数へ含めるか事前に固定する

## 10. ルール更新手順

1. v0.2の採点式、購入・売却閾値、対象、データ仕様を凍結する
2. v0.2を変更せず発見用期間へ適用する
3. 拾えた成功例、取りこぼした成功例、誤検出した失敗例を比較する
4. 各変更について、対象とする誤りと期待する改善指標を一つだけ定義する
5. 発見用期間だけでv0.3案を作る
6. 3年のパージ期間を挟んだ未見期間でv0.2とv0.3を一度だけ評価する
7. 事前に決めた主指標が改善しなければ変更を棄却する
8. 固定した版を最新時点の全銘柄へ適用する

過去の全テンバガーを説明することは目標にしない。偶然、粉飾、二値イベントだけで上昇した事例を無理に拾うと、現在の誤検出が増えるためである。

- [金融庁「資産形成の基本」](https://www.fsa.go.jp/policy/nisa2/invest/): 集中リスクを候補群上限・業種上限で管理する背景
- [Kaminski and Lo, When Do Stop-Loss Rules Stop Losses?](https://alo.mit.edu/topic/foundations-of-financial-behavior-and-adaptive-markets/page/3/): ストップルールの効果が価格過程と判定頻度に依存するため、固定閾値を対照戦略と比較する根拠
- [FINRA, Stop Orders: Factors to Consider During Volatile Markets](https://www.finra.org/investors/insights/stop-orders-factors-consider-during-volatile-markets): 発動価格と約定価格の乖離、短時間の急落による発動リスク
