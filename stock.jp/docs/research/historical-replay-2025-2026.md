## 1. 結論

PR #14と同じ日付別CSV契約で、契約範囲の公式日足を`data/daily-prices/`へ移植しGit管理した。2025年は243営業日・960,298行、2026年は1月5日〜6月8日の103営業日・404,782行である。先行期間を含む486営業日・1,918,292行は、列順、日付、コード重複、取得状態、OHLC、出来高、SHA-256の検証に合格した。

ただし、2026年6月9日〜8月31日の公式point-in-time価格、財務詳細、完全希薄化後株式数、当時の開示時刻、SAM/SOM、競合比較、TOPIXが不足する。したがって、入口ハードゲートと100点スコアを再生できず、2025年・2026年の銘柄別・合計損益はまだ算定しない。価格だけで0件売買または成功銘柄だけの損益を作り、PAPER承認の根拠にはしない。

## 3. 取得能力と不足

2026年8月31日に認証値をファイル、ログ、コマンド引数へ保存せず、公式APIの契約範囲を実査した。

| データ | 結果 | 履歴再生への影響 |
|---|---|---|
| 日足 | 2024-06-10〜2026-06-08、486営業日取得 | 2025年は通年、2026年は途中まで再生可能 |
| 銘柄マスタ | 25スナップショット、110,381商品行取得 | 上場廃止を含む当時コードの属性付与に使用 |
| 日次時価総額 | 1,834,451行取得 | 30億円以上1,000億円以下の入口判定に使用可能 |
| 調整後OHLC・調整係数 | 1,836,445行取得 | 分割・併合をまたぐ損益に使用可能 |
| 財務サマリー | 個別日で取得可能と確認 | 今回の価格アーカイブには未移植 |
| 財務詳細 | 契約外 | 粗利益、潜在株式等の入口判定が不足 |
| TOPIX | 契約外 | ベンチマーク比較が不足 |
| 2026-06-09〜08-31 | 契約期間外 | 2026年評価期間を完走できない |
| EDINET | 認証未設定 | 法定開示、潜在株式、監査、セグメントが不足 |

PR #14の`data/daily-prices/`には2026年8月12日〜31日の候補探索用データがある。ただしYahoo由来・現存銘柄一覧ベースであるため、公式point-in-time履歴の不足を閉じるデータとしては扱わない。株探による補完は行っていない。

移植完了後、取得用コード、通常運用のAPI呼出し、認証設定、fixtureを削除した。通常運用はEDINETの機械取得と、TDnet・JPX価格・コーポレートアクション・現物株カレンダーの一次サイト確認へ変更し、証跡が揃わない日は注文を止める。

## 4. 固定済み再生仕様

結果を見る前に次を固定する。

1. 2025年は2024年12月末評価から2025年最終営業日まで、2026年は2025年12月末評価から2026年8月31日までを対象とする。
2. 年別コホートに加え、2025年から2026年8月31日まで保有・現金を引き継ぐ連続ポートフォリオを主結果とする。
3. 各評価日より後に公表された財務、訂正、株式数、市場資料を遡及利用しない。
4. v0.2、v0.3、v0.4は同じ候補、同じ注文可能性、同じ費用、同じコーポレートアクションを使う。
5. 月末の翌営業日に、寄付値が`1.15 × PE`以下なら寄付値、寄付値が上限を超えて日中安値だけが上限以下なら指値上限で購入したとする。それ以外は未約定とし、出来高・値幅制限・売買停止も確認する。
6. 初期資産は比較用に1,000万円とする。v0.2とv0.3には100株単位、初回1%、候補群20%、同一業種6%、最大12銘柄、追加1回0.5%・最大2回を適用する。v0.4には100株単位、初回5%、候補群100%、同一業種20%、最大12銘柄、追加1回2.5%・最大2回を適用する。個人資産額を意味しない。
7. 主結果は売買1回につき約定代金の0.15%をスプレッド・スリッページ・手数料として控除する。0%と0.50%も感応度として併記し、税は口座依存のため別計算とする。
8. v0.3の5倍回収資金は、後日あらためて全入口条件を満たした候補へ実際に再配分できた場合だけ再投資効果へ数える。
9. 2026年8月31日の月末判定による注文は期間後のため、翌営業日アクションとして記録し、2026年8月31日損益へ先取りしない。
10. v0.4では投資済み比率、戦略待機資金比率、現金加重待機日数、銘柄別・業種別の最大損失寄与を追加報告し、未投資分を安全資産として除外しない。

## 5. PAPER受入条件

この履歴再生ゲート自体の受入条件は次のとおりである。すべてを満たした後にだけ、利用者が履歴再生を承認または棄却する。PAPERの経過日数と連続run数は別のLIVEゲートにしない。

1. 上場廃止を含むpoint-in-time全母集団を使用した
2. 入口の全ハードゲート、100点スコア、SAM/SOM、競合比較、10倍逆算、MRSを当時情報だけで判定した
3. `S-A`、`S-B`、価格・時間、部分利確、集中、再購入禁止を再生した
4. 銘柄別・年別・合計の損益と最大DDを費用控除後で提示した
5. 欠損や未約定を有利に除外せず、入力ハッシュと実行ログを残した
6. 利用者が結果を確認し、承認日時と根拠パスをprivateポリシーへ記録した

現時点では2〜4を完了できないため、`historical_replay_2025_2026_accepted`は`false`のままとする。
