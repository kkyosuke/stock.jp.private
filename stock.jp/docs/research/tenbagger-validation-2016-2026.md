# 日本株テンバガー仮説の予備検証（2016–2026年）

- 検証日: 2026年8月30日（休場日プレースホルダー除外を2026年8月31日に反映）
- 対象ルール: [日本株テンバガー判定ルール v0.1](../rules/tenbagger-rule-v0.1.md)
- 価格明細: [現存銘柄の10倍エピソード](../../data/tenbagger-survivor-price-episodes-2016-2026.csv)
- 結論の状態: **価格ラベルの予備検証は完了、100点ルールの正誤判定は未完了**

> 本資料の更新案は、2026年8月31日に[判定・運用ルール v0.2](../rules/tenbagger-rule-v0.2.md)へ反映した。v0.2は全母集団検証が終わるまでペーパートレード用暫定版として扱う。

## 結論

今回確認できたのは、「現在も上場している銘柄の中で、いつ10倍になり、その後どうなったか」である。2016年8月から2026年8月までを探索した結果、現在上場する内国普通株3,713銘柄のうち83銘柄に2年または3年の10倍エピソードがあり、3年ラベルは82銘柄、2年ラベルは55銘柄だった。

一方、v0.1の「70点以上ならテンバガー発生率が高まる」という中心仮説は、まだ正しいとも誤りとも判定できない。現在上場銘柄だけでは上場廃止銘柄が抜け、評価日時点の財務・完全希薄化後株式数・時価総額・開示日時・SAM・競合比較も揃っていないため、全銘柄の採点、対照群、適合率、再現率、リフトを計算できないからである。

ただし、ルール更新に使える強い結果は得られた。

1. 10倍到達は持続的成功と同じではない。`10x-3Y` 82銘柄のうち、2026年8月末にも取得価格の10倍以上だったのは24銘柄（29.3%）だけだった。
2. 10倍到達後の下落は極めて大きい。82銘柄の到達後最大ドローダウン中央値は−76.6%で、35銘柄（42.7%）が80%以上下落した。
3. 現在倍率の中央値は6.07倍だった。5銘柄は最終的に取得価格も下回った。
4. 3年候補の業種は18業種に分散した。上位はサービス業14、情報・通信業12、電気機器10、機械8であり、単一テーマだけでは説明できない。
5. 初値記録から評価日まで12か月未満のIPOは7銘柄あった。IPOを本体から分ける設計は比較可能性を高める一方、後に23.15倍を維持したジャパンエレベーターサービスHDも本体から外れるため、IPO専用トラックを実際に検証する必要がある。

したがって、v0.1を過去の成功例へ合わせて直ちに採点変更するのではなく、まず `durable-10x` と到達後リスクを正式な評価軸へ追加し、point-in-timeの全母集団データを取得してから70点閾値を検証するのが妥当である。

## 検証設計

### 価格ラベル

v0.1の定義どおり、各月末を評価日 `T0`、翌取引日終値を投資開始価格 `P0` とした。`P0` から2年または3年以内の月末終値が10倍以上なら成功とする。銘柄ごとの連続した成功月を数え上げず、最初の成功エピソードだけを集計した。

結果確認には次を追加した。

- データ最終日の倍率
- 10倍を現在も維持しているか
- 投資開始後から最終日までの最高倍率
- 10倍到達後の最大ドローダウン
- 最高値から最終日までの下落率
- 10倍到達後に取得価格を下回ったか

2年ラベルの完全判定対象はおおむね2024年8月まで、3年ラベルは2023年8月までの評価月である。2023年・2024年評価の銘柄は到達後の観測期間が短いため、古いコホートとの単純比較はしない。

### データ品質

2026年7月末の[JPX東証上場銘柄一覧](https://www.jpx.co.jp/markets/statistics-equities/misc/01.html)から内国普通株を抽出し、候補探索用にYahoo Financeの日次価格を使用した。Yahooが休場日に出力する「出来高0・前日終値据え置き」のプレースホルダーは売買可能な取引日ではないため除いた。そのうえで次のどちらかに該当する27コードは、コード再利用、再上場、株式分割調整不整合、長期売買停止または極端な低流動性の可能性があるため機械的に除外した。

- 隣接する終値の倍率が2.5倍超または0.4倍未満
- 取引日の間隔が45暦日超

除外ログは[品質監査CSV](../../data/tenbagger-survivor-price-episodes-2016-2026.quality.csv)に残した。たとえば8303は814暦日の価格欠損、9225は長い欠損をまたぐ2.75倍の価格ジャンプを検出しており、コード再利用やコーポレートアクションを見かけの成功に数える誤りを防いだ。一方、今回候補から外れた7901マツモトの54暦日ギャップのように、長期売買停止や低流動性として手動再確認すべき事例も含まれるので、27コードを失敗とは扱わない。

### 大きな制約

これは**サバイバー限定の成功例探索**であり、バックテストではない。JPXの上場廃止一覧には2017–2025年だけで643行、2026年1月から8月30日までに107行あり、少なくとも750件の上場廃止が今回の現在銘柄リストから抜ける。買収による正常な上場廃止も多いが、倒産や内部管理体制などの失敗例も含まれるため、これを落としたまま候補の勝率を計算すると過大評価になる。

また、CSVの会社名、市場、業種は2026年7月末時点であり、評価日時点の商号・市場区分とは限らない。Yahoo Financeの調整方法もJPX公式データと一致する保証がない。したがって、本資料の倍率は候補発見用であり、最終値はJPXの調整株価・コーポレートアクションで再計算する。

## 集計結果

| 指標 | `10x-2Y` | `10x-3Y` |
|---|---:|---:|
| 銘柄数 | 55 | 82 |
| 最終日も10倍以上 | 16（29.1%） | 24（29.3%） |
| 最終倍率中央値 | 5.11倍 | 6.07倍 |
| 到達後最大DD中央値 | −81.0% | −76.6% |
| 到達後80%以上下落 | 29（52.7%） | 35（42.7%） |
| 最終的に取得価格未満 | 6（10.9%） | 5（6.1%） |

`10x-2Y` と `10x-3Y` は重複し、合計は83銘柄にならない。2334イオレは完全判定可能な2年窓で10倍へ到達したが、3年窓はデータ最終日時点で未完成である。

市場区分別では、現行区分でスタンダード35、プライム31、グロース17だった。これは評価日時点の区分ではないので、区分別の成功率には使用しない。

## v0.1との照合

### 今回確認できたこと

| v0.1の設計 | 予備検証での観察 | 判定 |
|---|---|---|
| 月末10倍を主ラベルにする | 83銘柄を同一定義で抽出できた | 実装可能 |
| 2年と3年を分ける | 2年55、3年82で難易度差が明確 | 維持 |
| IPOを別トラックにする | 初値記録から12か月未満が7銘柄。持続例も含む | 別トラックを実装する |
| 業種・イベント型を分ける | 成功例が18業種に分散し、循環・バイオ・暗号資産等も混在 | 分離方針を維持 |
| 時価総額を固定ゲートにしない | point-in-time時価総額が未取得で比較不能 | 判定保留 |
| SAM・SOM・競合規模で逆算する | 過去時点の市場資料と競合スナップショットが未取得 | 判定保留 |
| 70点以上を候補にする | 全銘柄のpoint-in-time採点がない | 中心仮説は未検証 |
| レッドフラッグで脆い上昇を除く | 10倍後80%以上下落が42.7%あり、検証価値が高い | 次段階の主要検証対象 |

7銘柄のIPO判定は、Yahoo Financeの最初の出来高がある価格日を上場日の代理にした予備値である。最終検証ではJPXの当時点上場日を使う。

### なぜ100点ルールを今ここで採点しないか

過去の勝者だけを見て「合っていた」と採点すると、結果を知った後でSAM、競合、継続性、経営品質へ都合のよい説明を割り当てることになる。また、成功例だけでは70点未満の銘柄がどうなったか分からず、適合率もリフトも出ない。

公式のpoint-in-time検証に必要な上場銘柄、財務、調整株価の履歴は[J-Quants Pro](https://www.jpx.co.jp/markets/other-data-services/j-quants-pro/)で提供されることを調査時に確認した。JPXの公表資料では、上場銘柄一覧と調整株価は2008年5月以降、財務情報は2008年7月以降を収録する。ただし、2026年9月6日以降の運用方針ではJ-Quantsを使用しない。EDINET API v2は有価証券報告書本文を取得できるがAPIキーが必要であり、株価・上場履歴・開示日時を単独では補完しない。

この不足を二次サイトの最新値で埋めると、上場廃止バイアス、将来情報混入、修正財務の遡及使用が発生する。仮説を検証したように見せるより、価格ラベルと未検証部分を分離する。

## ルール更新案

次の変更はv0.2の候補とし、まだv0.1へ混ぜない。

1. 主ラベル `10x-3Y` に加え、到達後12か月の20日移動平均が8倍以上、またはデータ最終日が10倍以上となる「持続ラベル」を設ける。直近コホートは観測未完了として分ける。
2. 10倍到達後の最大ドローダウン、取得価格割れ、希薄化、上場廃止を副目的として最適化する。リフトが上がっても破滅的下落率が悪化する変更は採用しない。
3. IPOは除外で終わらせず、上場後3・6・12か月の専用評価日を持つ別モデルにする。
4. コード再利用、再上場、商号変更、分割・併合、45日超の売買停止をイベントテーブルで処理し、価格異常を人手確認なしに成功・失敗へ入れない。
5. `評価日時点の時価総額30億〜1,000億円` はハードゲートへ戻さず、規模帯、`必要時価総額 ÷ SAM利益プール`、`必要時価総額 ÷ 最大競合時価総額` の説明変数として比較する。
6. 保有中は四半期ごとに逆算を更新し、1株当たり粗利益、必要シェア、希薄化、資金余力、開示品質の仮説崩れを記録する。売却閾値はバックテスト前に別文書で固定する。

## 100点仮説を確定するための次の検証

1. 再生・保存が利用条件上許されたJ-Quants非依存の公式データと一次資料から、2016年8月以降の各月に存在した全銘柄、上場廃止、株価、株式数、四半期財務、公表日時を再構築する。欠損する期間は未検証のままとする。
2. 合併、株式交換、TOBは最終価格だけでなく受取現金・承継株式を含む投資リターンを計算する。
3. 全評価月・全銘柄にv0.1を機械適用し、欠損率を報告する。SAM、競合、経営品質は、機械スコア通過銘柄とマッチ対照群へ、将来リターンを伏せて二重レビューする。
4. 全銘柄、時価総額だけ、1株売上成長だけ、モメンタムだけと比較し、70点以上の適合率・再現率・リフト・大幅下落率を算出する。
5. 発見期間でv0.2案を作り、3年のパージ期間を置いた未見期間で一度だけ判定する。

この段階が終わるまでは、現在候補を「70点ルールで検証済み」とは呼ばない。今回の83銘柄はルールに合格した銘柄一覧ではなく、次の財務・市場仮説検証に使う正例候補である。
