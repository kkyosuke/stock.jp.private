# 過去の資料

この配下は当時の設計・運用・レビュー・移行の記録です。
現行の構成と操作手順は [資料一覧](../README.md) を参照してください。
古いパス・コマンド・運用状態は履歴として残しており、現行の入口には使いません。
外部のcommit URLと証跡のハッシュは当時の値です。

- `operations/`: 統合前の詳細な設計・手順。
- `reviews/`: 特定時点のレビュー。
- `migrations/`: 過去の配置調査。
- `state-migrations/`: 過去の設定・スキーマの保存記録。
