# 日本株の日次株価

日本株の日足を、取得元にかかわらずPR #14で固定した共通CSV契約でGit管理する。
日付別CSVは`YYYY/YYYY-MM-DD.csv`に置き、1ファイル内では1銘柄コード1行とする。

現在は次の2系列を収録している。

- 2024-06-10〜2026-06-08: 当日の銘柄コードを母集団にした公式履歴データ
- 2026-08-12以降: JPX「東証上場銘柄一覧」の現行内国株式とYahoo Financeの
  非公式chart endpointによる候補探索データ

後者は過去の継続収集系列である。現在のActionsは収集・更新PRを作成しない。`latest.json`はこの継続収集系列の最新カバレッジを示す。
公式履歴系列の期間・件数・日別SHA-256は
[`../historical-replay/price-coverage-2025-2026.json`](../historical-replay/price-coverage-2025-2026.json)
で監査できる。

## 列

- `日付`
- `銘柄コード`
- `銘柄名`
- `市場・商品区分`
- `33業種区分`
- `始値`
- `高値`
- `安値`
- `終値`
- `前日比`: 同じ取得系列における直前取引日の終値との差
- `前日比％`: `前日比 / 直前取引日の終値 * 100`
- `売買高(株)`
- `取得状態`: `OK`、`NO_QUOTE`、または`FETCH_ERROR`

公式履歴系列は日ごとの銘柄コードを使うため、銘柄数は日付ごとに変動する。
継続収集系列は現在の上場銘柄を母集団にするため、過去日に上場廃止済みだった銘柄は
含まれず、新規上場前の期間は`NO_QUOTE`になる。取得元や母集団の異なる系列を連結して
損益計算するときは、必ず日別の出所とpoint-in-time条件を確認する。

## 注意

Yahoo Financeのchart endpointは公式APIではなく、仕様・アクセス制限・提供継続は
保証されない。大量アクセスを抑えるため同時実行数を4に制限し、query1/query2の
フォールバックと再試行を行う。このデータだけで売買判断や注文票を作らず、一次情報と
照合する。

このフォルダは非公開stock.jp.private内に移行された。追加・更新する人は、取得元と元データ提供者の最新の
利用条件に照らして公開・保存が許されることを確認し、認証情報や生レスポンスをコミット
しない。
